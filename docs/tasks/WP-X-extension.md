# WP-X — Chrome side-panel extension "NaN" (`extension/` directory only, tests in `extension/__tests__/`)

A Manifest V3 extension that puts the NaN operator chat beside any page and can send the current page to Picked. It talks to the Picked backend over HTTP; the backend base URL is a setting (default `http://127.0.0.1:5198`, the hosted one is `https://pickedhq.pages.dev`). No build step, plain ES modules, no dependencies. Tests use `node --test` with `linkedom` (installed).

## Files
- `extension/manifest.json` — `manifest_version: 3`, `name: "NaN for Picked"`, `version: "0.1.0"`, `minimum_chrome_version: "114"`, permissions `["sidePanel","activeTab","scripting","storage","contextMenus"]`, `host_permissions: ["http://127.0.0.1:5198/*","https://pickedhq.pages.dev/*"]`, `background: { service_worker: "background.js", type: "module" }`, `side_panel: { default_path: "panel.html" }`, `action: { default_title: "NaN" }`, command `ask-nan` with default `Alt+Shift+N` ("Ask NaN about this page"). No `debugger`, no `nativeMessaging`, no all-sites host access.
- `extension/lib/extract.js` — exports `extractPage(document, url)` returning `{ url, title, description, headings: [{ level, text }] (max 30), text (visible body text, whitespace collapsed, max 8000 chars), jsonld: [object] (parsed <script type="application/ld+json">, skip invalid JSON, max 10), schemaTypes: [string] (all @type values found, including inside @graph and nested objects, deduplicated), hasFaq: boolean (a FAQPage type, or at least 3 question-like headings ending with "?"), canonical, lang, links: { internal: n, external: n } }`. Pure function over a DOM document; used both in tests and in the page.
- `extension/lib/api.js` — exports `getBase()`/`setBase(url)` (chrome.storage.local key `base`, validate http(s) URL, strip trailing slash), `post(path, body)` (JSON, 60 s timeout via `AbortSignal.timeout`, throws an Error with the server's `error` text; a `503` JSON body with `offline: true` throws an Error whose message is the body's `error`), and `isLocalBase(url)`.
- `extension/background.js` — opens the side panel on action click (`chrome.sidePanel.setPanelBehavior({ openPanelOnActionClick: true })`), creates the context-menu item "Ask NaN about this page" (contexts `page` and `selection`), and on the `ask-nan` command or the menu click opens the panel for that tab and stores the tab id and any selected text in `chrome.storage.session` (`pending`).
- `extension/panel.html`, `extension/panel.js`, `extension/panel.css` — the chat UI: header "NaN" with a status dot (green when `GET {base}/api/health` returns `ok`, amber with the text "NaN-Team đang tạm khóa để phát triển dự án" when it answers 503 or fails), a chip showing the current tab title, a message list, an input, and two buttons: "Review this page" and "Send page to chat". "Review this page" runs `chrome.scripting.executeScript` with `lib/extract.js` on the active tab (inject the function body; the page text is untrusted and must be set with `textContent`, never `innerHTML`), then `POST {base}/api/page/review` with `{ page }` and renders the returned `{ score, checks: [{ id, status: 'pass'|'warn'|'fail', label, detail }], summary }` as a list. Sending a chat message posts `{ text, original: text, state: { page: { url, title, description, schemaTypes, hasFaq } } }` to `{base}/api/one/chat` and shows `reply`. A settings row lets the user change the backend base URL. Light theme, system font, compact.
- `extension/README.md` — how to load it unpacked, what each permission is for, what it never does (no cookies, no keystrokes, no background reading of pages; it reads a page only when the user presses a button or the shortcut).

## Tests (offline)
`extension/__tests__/extract.test.mjs` with `linkedom`: headings and text limits; JSON-LD parsing with an invalid block skipped; `@graph` and nested `@type` collection; `hasFaq` by type and by headings; canonical, lang, description; internal vs external link counts; hidden text (`script`, `style`, `noscript`) excluded. `extension/__tests__/manifest.test.mjs`: the manifest parses, MV3, only the permissions listed above, no `debugger`/`nativeMessaging`/`<all_urls>`, every file the manifest references exists, the command exists. `extension/__tests__/api.test.mjs`: with a fake `chrome.storage` and a fake `fetch`, `setBase` rejects non-http URLs and strips the trailing slash, `post` surfaces the server error, 503 offline message, and times out.
