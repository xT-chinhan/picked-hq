# WP-M — MCP hub (`server/mcp.mjs`, `server/__tests__/mcp.test.mjs`, `server/__tests__/fixtures/fake-mcp-server.mjs`)

Let Picked connect to the user's own MCP servers (stdio) and let agents call their tools. No dependency: implement the small part of the MCP protocol that is needed. Protocol: newline-delimited JSON-RPC 2.0 over the child process stdin/stdout. Handshake: send `initialize` (`protocolVersion: "2025-06-18"`, `capabilities: {}`, `clientInfo: { name: "picked", version: "1.0.0" }`), wait for the result, then send the notification `notifications/initialized`. Tools: `tools/list` → `result.tools: [{ name, description, inputSchema }]` (follow `nextCursor` until absent); `tools/call` with `{ name, arguments }` → `result.content: [{ type: 'text', text }, ...]`, `result.isError`.

## Exports
1. `createMcpHub({ file, spawnImpl = child_process.spawn, now = Date.now })` → hub. `file` is a JSON file that stores the server definitions; write it atomically (temp file + rename) with mode `0o600` because `env` may hold secrets.
   - `hub.add({ name, command, args = [], env = {} })` — `name` matches `^[a-z][a-z0-9_-]{1,30}$`, `command` is a non-empty string, `args` an array of strings, `env` an object of strings; at most 12 servers; duplicate name throws. Returns the public view.
   - `hub.remove(name)` (stops the process first), `hub.list()` → public views `{ name, command, args, envKeys: ['KEY'], status, toolCount, error, startedAt }`. **Never return env values**, only their keys. `status` is `stopped | starting | ready | failed`.
   - `await hub.connect(name, { timeoutMs = 15000 })` — spawn with `env: { ...process.env, ...server.env }`, run the handshake, load all tools, set `ready`. On timeout, spawn error, early exit or a JSON-RPC error: kill the process, set `failed` with a short `error`, and throw. Calling `connect` on a ready server returns immediately. A server that exits later becomes `stopped`.
   - `await hub.tools(name)` → connected tools `[{ name, description, inputSchema }]` (connect first when stopped).
   - `await hub.call(name, tool, args = {}, { timeoutMs = 60000, scope })` → `{ text, isError, ms }` where `text` joins all text content parts with a newline. If `scope` (an array of allow patterns) is given and `isAllowed(scope, name, tool)` is false, throw an error with `code: 'forbidden'` before any request is sent. Unknown server/tool → `code: 'not_found'`. Timeout → `code: 'timeout'` (the request is abandoned, the server keeps running). Responses are matched to requests by `id`; ignore server notifications and responses for abandoned ids; handle partial lines split across chunks.
   - `await hub.stopAll()`.
2. `isAllowed(scope, server, tool)` — a scope entry is `native:*` (ignored here), `mcp:<server>:<tool>`, `mcp:<server>:*` or `mcp:*`. Returns true when any entry matches. Empty or missing scope → false.
3. `handleMcpRequest(req, res, { hub, local })` → `Promise<boolean>` (false for other routes). `local` is a boolean: when false every route except `GET /api/mcp/servers` answers `403 { error: 'local only' }`. Routes (JSON, body limit 20 KB): `GET /api/mcp/servers` → `{ servers }`; `POST /api/mcp/servers` add; `DELETE /api/mcp/servers/:name`; `POST /api/mcp/servers/:name/connect` → `{ server, tools }`; `GET /api/mcp/servers/:name/tools`; `POST /api/mcp/call` body `{ server, tool, arguments }` → result. Errors: `400` bad input, `403` forbidden, `404` not found, `504` timeout, `502` any other failure, with `{ error, code }`.
